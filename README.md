# サブスク洗い出し

カードの利用明細（CSVファイル、または明細画面からコピーした文字）を入れると、毎月出ている支払いと年払いを一覧にして、月あたり・年の目安の合計を出すWebページです（100日100プロダクト Day063）。

- 明細はブラウザの中だけで処理します。送信も保存もしません（ページを閉じると消えます）
- AI・外部APIは使っていません。支払先の名前と金額の文字の照合と集計だけです
- 「見直したい」の印は利用者が付けます。契約を続けるか・見直すかは判断しません
- サンプルは架空の支払先・金額です

## 判定のしかた
- 毎月: 読み込んだ期間のすべての月に同じ支払先が出ているもの（金額が同じか、変わるか）
- 年払い（明細から判定）: 同じ支払先・同じ金額が約1年（335〜395日）の間隔で2回以上出ているもの。約13か月分以上の明細が必要です
- 年払い（自分で追加）: 1回だけ出ている支払いを、利用者が「年払いとして加える」で一覧に入れたもの
- 年の目安は月額×12（年払いはその金額）。分割払いも毎月同じ額として出ることがあります

## 限界・未確認
- 実際のカード会社の明細（CSVの列名・文字コード・日付の書き方）では確認していません。サンプル（架空の形式）でのみ確認しています
- iPhone・Androidでの「CSVファイルを選ぶ」とコピーの動作は未確認です
- 年が書かれていない日付（例: 9/5）、マイナスの金額（返金・取消）は読み取らず、理由つきで「読み取れなかった行」に出します

## 検算
- `node source/run-checks.js`（計算コア）
- `node source/e2e.js`（Chromeのヘッドレス実行で画面操作・375px）
